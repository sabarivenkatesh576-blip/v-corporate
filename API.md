# V-CORP REST & WebSocket API Documentation

## Base URL
http://localhost:5000/api

## Authentication
JWT Bearer token required in the Authorization header: Authorization: Bearer <JWT_TOKEN>

## Endpoints
- /api/auth: Registration, Login, Profile
- /api/companies: 15+ MNC hiring stages & topics
- /api/placements: Placement drives & dynamic eligibility
- /api/internships: Verified internships & skill matching
- /api/communication: AI Style Manager & 8 coaching modes
- /api/projects: 200+ projects & 7 workspace runners
- /api/assessment: 600+ questions across Quant, Logic, Verbal
- /api/interview: Multi-turn conversational AI Mock Interview
- /api/teams: Squad join codes & real-time chat
- /api/meetings: WebRTC conference rooms & minutes
- /api/credentials: Verifiable credentials & QR codes
